Douteux : les avis divergent

E160f · Ester éthylique de l'acide bêta-apo-8'-caroténoïque

Cet additif est fabriqué par synthèse, mais le MUIS le classe quand même douteux. Peu de sources le citent précisément.

Origine

Synthétique

Pourquoi c'est permis

  • Le MUIS (Singapour) le décrit comme synthétique, donc sans origine animale citée.

Pourquoi c'est interdit

  • Le MUIS (Singapour) le classe douteux (syubhah).
  • Le mufti Abdullah Patel (Darul Uloom London) range le groupe E160 parmi les codes à éviter, sans citer ce code en particulier.

Sources

  • MUIS (Singapour) - Liste des additifs alimentaires (2016)
  • MuftiSays (Darul Uloom London) - Liste des codes E halal, douteux, haram
