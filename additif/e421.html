Halal d'après les sources

E421 · Mannitol

Le mannitol est un sucre-alcool présent dans les algues, ou fabriqué à partir de sucres. Ce n'est pas de l'éthanol. Les sources consultées le jugent permis.

Origine

Végétale (algues) ou synthétique (à partir du fructose)

Pourquoi c'est permis

  • Le mufti Shafiq Jakhura (Darul Ihsan, Durban) juge permis les sucres-alcools, et cite le mannitol tiré des algues.
  • Le portail Fiqh d'IslamOnline cite le mannitol parmi les sucres-alcools permis : ils n'enivrent pas et la règle générale du permis s'applique.
  • Le mufti Abdullah Patel (Darul Uloom London, école hanafite) dit que tous les autres codes E sont halal, sauf une liste d'exceptions qui ne contient aucun code de la série E400 à E430.

Pourquoi c'est interdit

Aucun avis contraire trouvé dans nos sources.
