Douteux : les avis divergent

E630 · Acide inosinique

Acide inosinique peut venir de sources animales ou végétales. Les sources consultées demandent de vérifier l'origine.

Origine

Variable (animale ou végétale)

Pourquoi c'est permis

  • Le Darul Uloom de Trinité-et-Tobago dit que ce code n'est pas forcément haram : l'origine peut être animale ou végétale.

Pourquoi c'est interdit

  • La SANHA (Afrique du Sud), citée par le Darul Iftaa (hanafite), le classe mashbuh (douteux) : il faut vérifier l'origine.

Sources

  • Askimam (Darul Iftaa, hanafite) - Liste de codes E, classement SANHA
  • Darul Uloom Trinité-et-Tobago - E-Numbers

Information à titre indicatif. Elle ne remplace pas l'avis d'un savant.
