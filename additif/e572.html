Douteux : les avis divergent

E572 · Stéarate de magnésium

Le stéarate de magnésium vient de l'acide stéarique, d'origine animale ou végétale. Il est classé douteux, mais permis si l'origine est végétale.

Origine

Animale ou végétale

Pourquoi c'est permis

  • Des savants hanafites (SeekersGuidance) l'autorisent : la matière est transformée chimiquement, et son usage est très répandu.
  • IslamicPortal (hanafite, Royaume-Uni) dit qu'il est permis s'il est d'origine végétale. Si l'origine est animale, il faut chercher une autre version.
  • Le Vegetarian Resource Group note qu'en pratique il est surtout fait d'huiles végétales (palme, coco). Ce n'est pas un avis religieux.
  • Le Darul Uloom de Trinité-et-Tobago dit que ce code n'est pas forcément haram : l'origine peut être animale ou végétale.

Pourquoi c'est interdit

  • La SANHA (Afrique du Sud), citée par le Darul Iftaa (hanafite), le classe mashbuh (douteux).
  • Le MUIS (Singapour) le classe douteux : c'est le sel de magnésium de l'acide stéarique.
  • IslamicPortal n'admet l'origine animale qu'en cas de nécessité, faute d'alternative.
