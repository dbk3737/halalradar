Halal d'après les sources

E406 · Agar-agar

L'agar-agar est extrait d'algues. Il sert de substitut végétal à la gélatine. Les sources consultées le jugent permis.

Origine

Végétale (algues rouges)

Pourquoi c'est permis

  • Le site de questions-réponses I.M.A.M. dit que l'agar est halal : il vient d'algues, donc d'une plante.
  • Le mufti Faisal al-Mahmudi (Fatwa.ca) juge permis l'extrait d'algues, dont l'agar : c'est un produit végétal, sans raison de l'interdire.
  • Le mufti Abdullah Patel (Darul Uloom London, école hanafite) dit que tous les autres codes E sont halal, sauf une liste d'exceptions qui ne contient aucun code de la série E400 à E430.

Pourquoi c'est interdit

Aucun avis contraire trouvé dans nos sources.
