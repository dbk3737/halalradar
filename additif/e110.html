Halal d'après les sources

E110 · Jaune orangé S (jaune soleil FCF)

Ce colorant orangé est fabriqué par synthèse. Les muftis consultés le jugent permis.

Origine

Synthétique

Pourquoi c'est permis

  • Le mufti Abdullah Patel (MuftiSays, Darul Uloom London) dit qu'il est permis : c'est un colorant de synthèse tiré du goudron de houille.
  • Le mufti Faisal al-Mahmudi (IlmHub) le juge halal : il est synthétique, issu du pétrole.
  • Le Halaal Department (Malawi) le classe halal, d'origine synthétique.

Pourquoi c'est interdit

Aucun avis contraire trouvé dans nos sources.
