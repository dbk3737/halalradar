E270 · Acide lactique

L'acide lactique est surtout fabriqué par fermentation, mais l'étiquette ne dit pas l'origine. Les sources divergent : un site le juge à vérifier.

Origine

Le plus souvent fermentation de sucres ; une origine animale est possible selon le fournisseur

Pourquoi c'est permis

  • Le mufti Abdullah Patel (Darul Uloom London, école hanafite) déclare halal tous les codes E, sauf une courte liste d'exceptions (E473 à E478, E631, E635, E640, E920). Ce code n'est pas dans la liste.
  • Selon Halal Food AI, il est le plus souvent obtenu par fermentation, ce qui est un procédé permis.

Pourquoi c'est interdit

  • Halal Food AI le classe « suspect » : certaines livraisons industrielles viendraient de sources animales, et l'étiquette ne l'indique pas.
  • Il conseille de l'éviter sauf si l'étiquette indique une source végétale ou s'il y a une certification halal reconnue.

Peu de sources parlent précisément de cet ingrédient. Confirme auprès d'un savant en cas de doute.
